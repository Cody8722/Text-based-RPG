# 青石鎮

一個會自己過日子的江南小鎮。你只是剛好走了進來。

鎮上的人有自己的作息、難處、恩怨和秘密，會自己做決定；事情一件引發一件，消息在人與人之間流傳、走樣。
你可以介入，也可以旁觀——世界不會等你，但會記得你做過什麼。

## 開始玩

需要 Python 3.10 以上，不用安裝任何套件：

```bash
python -m rpg
```

瀏覽器會自動打開 `http://127.0.0.1:8765/`。進度會自動存檔。

如果本機有 [Ollama](https://ollama.com/) 並已下載 `qwen3.5:9b`，遊戲會自動請它當說書人，把故事講得更生動；沒有也完全可以玩。

## 比較本機說書模型

先用 Ollama 下載想比較的模型，再執行：

```bash
python -m tests_llm --compare --quick
```

不帶模型名稱時，程式會直接探測本機 Ollama 已下載的生成模型（自動略過嵌入模型）；指定模型名稱時則只測指定項目。加上 `--quick` 可只跑快速代表性情境；不加則執行完整情境集。它會先列出測試清單和時間粗估，等你確認後才開始，不需要修改 `.env` 或手動切換 `RPG_MODEL`。估時優先參考本機前次實測；首次測試則按模型大小粗估。報告會比較敘事接受率、退回原因與生成速度，完整紀錄寫在 `tests_llm/reports/`。也可以自行指定模型：

```bash
python -m tests_llm --compare qwen3.5:9b "hf.co/AtomicChat/Qwen3.5-4B-GGUF:Q4_K_M" --quick
```

## 操作

- 下方是你現在能做的事，數字鍵 1–9 可以快速選擇；跟人交談時可以直接打字說話。
- 右側：此地、見聞錄（你聽說和看見的事）、人物、足跡（你做過的事）、行囊。
- 每個動作都會花時間。
